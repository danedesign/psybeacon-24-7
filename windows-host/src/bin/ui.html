Host requirements Windows

Run this app as Administrator. Install the Parsec virtual display driver and an FFmpeg build with NVENC support, then allow inbound UDP 43701 and TCP 43703 through Windows Firewall.

Connect to a PC

Enter a reachable LAN or Tailscale IPv4 address on Home. The viewer uses FFmpeg to decode the stream, so FFmpeg must be on this PC’s PATH. Allow inbound UDP 43702 for video.

Current video mode

The Windows viewer currently supports one display. Video is decoded to JPEG frames inside this window; a later Direct3D renderer will be needed for the project’s low latency, 120 Hz goal.
